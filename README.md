# GitHub Pages 上传说明

1. 在 GitHub 新建一个 Public 仓库，例如 `cat-personality-test`。
2. 将本压缩包内的全部文件上传到仓库根目录。
3. 打开仓库 Settings → Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，文件夹选择 `/ (root)`，点击 Save。
6. 等待几分钟，GitHub 会生成网站链接：
   `https://你的用户名.github.io/cat-personality-test/`

上传时请上传本压缩包内的文件本身，不要再套一层文件夹。
